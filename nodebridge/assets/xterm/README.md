# Bundled xterm.js assets / 随程序提供的 xterm.js 资源

These local runtime assets come from the maintained npm packages [`@xterm/xterm` 6.0.0](https://www.npmjs.com/package/@xterm/xterm/v/6.0.0) and [`@xterm/addon-fit` 0.11.0](https://www.npmjs.com/package/@xterm/addon-fit/v/0.11.0). The JavaScript and CSS are copied from their published package archives without modification. Both use the MIT license; the original license texts are included here. No Node.js, npm, CDN, or Internet connection is needed at runtime.

这些本地运行资源来自持续维护的 npm 包 [`@xterm/xterm` 6.0.0](https://www.npmjs.com/package/@xterm/xterm/v/6.0.0) 和 [`@xterm/addon-fit` 0.11.0](https://www.npmjs.com/package/@xterm/addon-fit/v/0.11.0)。JavaScript 和 CSS 直接从发布包复制，未作修改。两者均采用 MIT 许可证，原始许可证文本已附在此目录。运行时不需要 Node.js、npm、CDN 或互联网连接。

Windows portable builds must include this directory, `../terminal.html`, `../terminal.js`, and the Qt WebEngine resources supplied by PySide6.

Windows 绿色版打包必须包含本目录、`../terminal.html`、`../terminal.js`，以及 PySide6 提供的 Qt WebEngine 资源。
