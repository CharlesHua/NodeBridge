# NodeBridge 使用指南

CPU／内存监控在本次运行首次进入“终端”标签页后才启动；仅连接直连站点、停留在文件页不会触发资源查询。首次进入后，即使切回文件页也会继续后台更新。重启软件后重新等待首次进入终端页。

Windows 启动稳定性修正：默认关闭自动原生崩溃栈捕获，避免 Python 栈输出器自身崩溃。普通程序错误、线程异常和 Qt 警告仍记录到 `errors.log`；`crash.log` 记录此配置说明。原生故障可查看 Windows“事件查看器 → Windows 日志 → 应用程序”；下文有关原生栈记录的说明仅适用于手动启用捕获时。

“终端 → 节点与终端”列表的 CPU、内存列显示整台 Linux 节点的使用情况（包括其他用户的进程）。CPU 是两次采样之间的平均利用率，全部逻辑核归一到 100%，首次显示“采样中”；内存显示使用百分比及“已用/总量 GiB”，使用量按总内存减可用内存计算。悬停可查看更新时间或失败原因。程序使用独立后台连接，每轮采样后等待 5 秒，最多并发两个查询，因此节点较多或响应慢时实际刷新间隔会更长；失败节点等待 30 秒再试。无需安装 htop，节点须提供 Linux `/proc`。断开直连站点或退出软件会停止监控；资源查询失败不会主动断开终端或文件连接。

站点管理器中可勾选“打开软件时自动连接此站点”，保存后下次启动生效。仅支持一个启动直连站点，选择另一个会替换原选择，复制站点不会复制此勾选。主密码模式先询问解锁；不保存密码且未指定私钥时询问连接密码，免密登录可留空。取消提示则保持未连接，连接失败可手动重试。

向多个间接节点复制时，若部分节点缺少目标目录，程序会询问“新建路径并复制”或“跳过此节点”，可展开详情查看需要创建的各级目录。“总是使用此操作”仅对本次复制任务的后续缺失路径生效，下次复制重新询问。已有目标目录的节点照常复制；权限不足或同名文件阻挡路径会报告失败。中途失败时，已创建的目录及已完成的副本不会自动回滚。

NodeBridge 用于浏览和复制本机、直连节点以及经直连节点到达的间接节点上的文件，也提供多节点 SSH 终端。当前版本优先支持 Windows。界面上的“直连节点”通常是跳板机，“间接节点”是通过它连接的工作节点。

## 连接站点与发现节点

可以在主窗口填写主机、用户名、密码或私钥路径后连接，也可以在“站点管理器”中保存具名站点。首次连接前，请通过可信渠道核对服务器主机密钥指纹；未知或变更的主机密钥不会自动接受。站点管理器提供不保存密码、明文保存、主密码保护三种方式。明文站点文件和备份可能包含密码，分享程序目录前请检查。

连接直连节点后，文件页可从其 SSH 配置和 `/etc/hosts` 发现间接节点。发现的名称只是候选项；程序会再尝试免密 SSH 探测。探测失败的节点显示为灰色，但仍可再次勾选并尝试连接。也可点“添加间接节点…”手动输入别名，例如 `cft02`，无需输入 `ssh cft02`。间接节点要求跳板机能够免密登录目标，目标提供 SFTP 服务，且跳板机已信任目标主机密钥。

节点列表中的复选框用于连接或断开节点；按住 Shift 点击第二个复选框可连续勾选或取消勾选。连接／断开操作后，勾选会清空。文件复制、删除和新建目录的多节点范围由操作时的询问框决定，通常可选当前节点或所有**已连接**节点。

## 文件浏览与复制

复制在后台运行，传输期间仍可浏览本地、直连和间接节点。一次只能运行一项复制；完成前不能断开相关连接或修改文件。同名文件需要选择覆盖、跳过或取消时，程序会弹出提示。将远程文件拖到 Windows 资源管理器前，仍需先准备拖动用的临时数据，实际拖动会等待准备完成。

“文件”页可显示本地、直连和间接节点。使用地址栏、目录树、双击文件夹、“上一级”与“刷新”浏览目录。间接节点可切换单节点查看和合并查看；再次进入目录或切换显示节点时会重新读取对应目录。单节点模式切换节点时，优先读取当前绝对路径；该路径不存在时逐级尝试父目录，直到根目录。权限不足或连接失败会直接报告，不自动上移。“查看 → 查看本地站点”控制本地栏是否显示，程序会记住该设置及上次打开的本地目录。

从本地文件栏、Windows 资源管理器或桌面拖入直连／间接节点文件栏，可以复制文件或文件夹。拖到文件夹行会复制进该文件夹，拖到空白处会复制进当前目录。向多个间接节点复制时，放开鼠标后再选择只复制到当前节点或并行复制到所有已连接节点。来源是本地文件时，程序直接将其内容写入目标节点，不会使用跳板机上同名的文件。

从间接节点拖到程序内的直连或本地文件栏，可以选择当前节点或所有已连接节点作为来源。汇集时只给每个**顶层**名称追加节点后缀，例如 `results_cft02`、`output_cft03.txt`；文件夹内部名称保持不变，来源文件仍保留。当前不支持把间接节点的项目直接拖到 Windows 资源管理器或桌面。从直连节点拖到资源管理器会先准备临时本地副本，资源管理器目标处的同名冲突由 Windows 处理；若要由 NodeBridge 处理同名冲突，请使用“下载到…”。

NodeBridge 内的复制若遇到同名文件，会显示来源、目标、大小和修改时间，并询问“覆盖”“跳过”或“取消”。“总是使用该操作”只作用于本次传输。已有文件夹会合并，文件冲突仍分别处理。复制符号链接和特殊文件暂不支持。任务中途失败时，已完成的文件与目录可能仍留在目标处；批量操作下方的结果表会列出各节点结果。

## 文件操作与内容核对

本地或直连节点的文件列表支持右键复制、重命名、删除，也可使用 Ctrl+C、Ctrl+V、F2、Delete。选中文件后再次单击文件名可直接编辑，Enter 确认，Esc 取消；右键空白处可创建目录或创建后进入。本地删除经确认后移入 Windows 回收站；远程删除经确认后永久执行，无法撤销。

间接节点的文件列表可右键或按 Delete 删除选中项目。程序会询问当前节点或所有已连接节点，再单独确认永久删除。间接节点路径旁或文件列表右键菜单可新建目录；若部分节点已有同名目录，可选择跳过，或在冲突节点创建 `名称 (2)` 等带序号的目录。任何节点的创建前检查失败时，整批创建不会开始；开始后若部分节点失败，已完成节点不会自动回滚。

合并视图每次读取目录后，会在后台自动比较所有已连接间接节点**同一绝对路径**下同名、同大小普通文件的 SHA-256；不用先选中文件或点击按键。缺失和大小不同直接显示，哈希任务的等待、运行及结果显示在“差异”栏，进度显示在状态栏。远程节点计算摘要，软件不下载完整文件；校验失败时，将鼠标停在对应差异项可查看逐节点原因。自动检查使用独立连接，不占用文件操作的任务槽；切换目录或节点时会取消过期检查。程序不再提供手动核对按钮或单独的核对报告。当前不递归核对目录，也不在复制后验收目标内容；大量大文件可能需要较长时间。

刷新合并目录时，程序先读取新的文件信息。若节点连接、绝对路径、大小、修改时间及文件类型与上次一致，会复用最近 60 秒内的 SHA-256 比较结果，鼠标悬停可看到缓存说明。超过 60 秒后再次刷新会重新计算；通过程序进行文件操作也会清除缓存。文件如果被外部工具改写却保留大小和时间，短期内可能无法仅靠这些信息发现，缓存不作为复制验收依据。

## 终端与广播

节点可连接性检测结果也会显示在终端节点列表中：不可连接的节点名称和状态呈灰色，但仍可选择并重试。之后在文件页或终端页实际连接成功，会恢复正常显示。连接文件页的多个间接节点时，仍可浏览和操作本地、直连站点；断开直连站点或关闭程序须等待连接结束。

“终端”页的节点列表不依赖文件页的间接节点 SFTP 连接，但仍需要直连节点连接。可对同一节点打开多个独立终端；勾选多个节点后连接会形成一个可重命名的终端组。关闭终端标签只隐藏视图，重新从节点列表打开即可；“断开终端”才会关闭 SSH 通道。多终端组默认显示只读的联合视图，单终端组默认显示该终端。

点击黑色终端区域即可直接输入命令。Enter 执行，Ctrl+C 中断，Tab 交给远程 Shell 补全；远程 Shell 发出 BEL 时会响铃。终端显示 ANSI 颜色、光标和进度行。终端标签栏右侧的下拉菜单可快速切换当前打开的终端与联合视图。

广播时先选终端组，再勾选该组内的目标终端，每个节点最多接收一次。命令只发送给当前组。程序会检查空闲 Shell 的实际工作目录；目录不同或无法确认时会要求手动确认，常见破坏性命令还会再次确认。联合视图按节点顺序拼接各终端的提示符、命令回显和反馈；广播状态表示命令已提交发送，**不代表远端执行成功**。广播框下方的常用命令按钮会将模板放入最近获得输入焦点的广播框或单终端输入位置，不会立即执行。

广播框支持多行输入和粘贴：Shift+Enter 换行，Enter 或“发送命令”发送整个输入框。请确认所填内容是要发送到每个目标终端的完整命令；它们在各节点按输入顺序执行，某一行失败不会自动撤销前面已执行的操作。

在“工具 → 常用命令管理”中，可编辑预置命令、添加或删除自定义单行命令。每行前的勾选决定该命令是否显示在常用命令栏。功能介绍可不填；填写后，按钮显示为“命令（功能介绍）”。点击“保存”后立即生效，重启仍保留；点击命令按钮只替换当前输入，不会立即执行。终端面板较窄时，常用命令按钮自动分成多行；拉宽面板后会重新排列。

## 日志与绿色版资料

“查看 → 查看日志”可显示或隐藏窗口底部的操作日志，拖动分隔条可调整高度。“查看 → 打开日志文件”打开持久操作日志；其中记录文件操作和连接事件的开始、结果、路径及逐节点错误，不主动保存终端输出或密码。警告、程序错误和未捕获异常另记于同目录的 `errors.log`；`crash.log` 尽可能记录原生崩溃，也可能为空。分享这些文件前请检查其中的本机路径和异常细节。

源码运行时，站点资料和日志位于 Windows 用户本地应用数据目录。绿色版的设置、站点资料和日志位于 `NodeBridge.exe` 旁的 `data` 目录。更新绿色版时保留自己的 `data`，替换程序和 `_internal` 文件夹；发行压缩包不包含 `data`。完整绿色版构建与更新说明见仓库中的 `PORTABLE.md`。
